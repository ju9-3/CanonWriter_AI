# CanonWriter AI小说创作工具
同人文/小说/故事 AI辅佐项目，可以通过上传已有的设定文件，利用该demo去检索对应信息、输入需求生成文章
## 面向对象
针对长篇小说创作中人物设定、世界观、时间线易混乱，以及AI续写容易出现人物OOC、剧情冲突等问题，面向小说作者与二创用户，搭建基于RAG的长文本一致性创作助手，实现原作检索、正文生成与一致性校验的完整链路
## 项目结构
Python后端 + 静态HTML前端
- backend：Python后端服务
- frontend：前端页面
## 后端启动
1. 创建虚拟环境
2. 激活虚拟环境，安装依赖
3. 复制 `.env.example` 重命名为 `.env`，填入你的密钥
4. 运行 `run_api.bat` 启动后端接口
## 前端启动
直接打开html文件，或者双击start.bat
